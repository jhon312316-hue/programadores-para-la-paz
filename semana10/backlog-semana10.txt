BACKLOG - SEMANA 10
Prioridad 1
Como ciudadano quiero registrar una denuncia ambiental para dejar evidencia y facilitar el seguimiento del caso.
Prioridad 2
Como coordinador quiero recibir una notificación en Telegram cuando se registre una nueva denuncia para revisar el caso oportunamente.
Prioridad 3
Como miembro del equipo quiero consultar el listado de reportes para hacer seguimiento a cada caso.
Prioridad 4
Como administrador quiero actualizar el estado de las denuncias para mantener informada a la comunidad.
Prioridad 5
Como ciudadano quiero conocer el estado de mi reporte para saber si ya fue atendido.
