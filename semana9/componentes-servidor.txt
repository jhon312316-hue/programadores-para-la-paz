Sistema operativo:
Es el software principal que administra los recursos del computador o servidor. Permite ejecutar programas, controlar el hardware y gestionar los procesos del sistema.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas, las respuestas y el comportamiento de la aplicación.

Puerto:
Es un punto de comunicación que permite al servidor recibir solicitudes de los usuarios. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre eventos, errores y actividades del sistema. Ayudan a monitorear y solucionar problemas en el servidor.
